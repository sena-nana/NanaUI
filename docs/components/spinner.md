# Spinner

`spinner()` 创建一个不定进度的转圈。模板里的标签是 `<Spinner>`。它没有构造参数，内部是 `Spinner::new("")`。

## 基本用法

:::api

```rust view
use nana_ui::runtime::view;

view! {
    <Spinner label="正在加载" />
}
```

```rust rust
use nana_ui::runtime::view::spinner;

spinner().label("正在加载")
```

:::

`label` 可以是常量、`Signal<Arc<str>>` 或闭包。它也是无障碍名字。控件标成忙。

## 标签

字段只有 `label: Arc<str>`。没有事件，也没有 `model`。空标签就是一个转圈。有标签时，转圈贴在文字左边，作为前置槽。有标签时，左边距是转圈自己的槽，归框架。另外三边才是调用方的内边距。

## 旋转

挂载之后，旋转由 Motion IR 的无限时间线驱动。宿主不逐帧喂 phase。投影只会在还没转的时候启动这条时间线，不会把已经在转的相位拨回去。

停用是卸载或停放该节点。停放保留节点身份和应用状态，但退出布局、绘制、输入、焦点和无障碍，直到这棵子树再插回去。藏起来（布局 `hidden`）时时间线也停，不为一个看不见的转圈把宿主留在醒着。不要自己写相位去暂停。相位归动画调度，不在字段表里。

时间线线性重复，没有播放完的一帧。重复投影不会把相位拨回 0。

## 尺寸

尺寸在组件 `Spinner::size` 上，不是 `<Spinner>` 的属性。非有限或非正的尺寸会退回默认。

## 无障碍

无障碍角色是进度指示，并且一直标成忙。空标签仍然是这个角色，只是名字为空字符串。

## 封面

封面一类的加载转圈是 `Thumbnail` 自己画的，居中，边长是紧凑 `Spinner` 的两倍。那不是这一页的控件。带标签的独立 `Spinner` 仍贴左。

## 属性

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `label` | `Arc<str>` | 字段只有这一个。可以是常量、`Signal<Arc<str>>` 或闭包，也是无障碍名字。空标签就是一个转圈 |
| `Spinner::size` | — | 在组件上，不是 `<Spinner>` 的属性。非有限或非正的尺寸会退回默认。相位不在字段表里 |

## 事件

| 事件 | 载荷 | 说明 |
| --- | --- | --- |
| 无 | 无 | 没有事件，也没有 `model` |
