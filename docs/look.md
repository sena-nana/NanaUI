# 视觉

NanaUI 的界面是给桌面产品用的：深色和浅色、紧凑、弱分隔、蓝色只出现在真正的主操作上。颜色、状态和密度跟 Nana 系列已经在用的界面一致，不另发明一套「接近」的皮肤。

所有能看见的按钮、开关、菜单项都要连到真实状态。不要放还没接上的入口。

## 尺寸

单行控件只有三档高度：

| 档位 | 高度 | 用在 |
| --- | ---: | --- |
| 小 | 28px | 导航、菜单、列表、紧凑图标 |
| 中 | 32px | 表单、按钮、选择、常规操作 |
| 大 | 36px | 需要强调、由你显式选的场合 |

按钮、输入、选择、复选框、开关、Tab、列表和侧栏都吃这三档，不再每个控件自己定一行有多高。多行内容（多行文本、卡片、对话框、工作区）按内容长，但里面的单行操作仍走这三档。

标准正文是 13px。辅助文字更小，标题更大，不要为了「统一」把所有字都拉成同一个号。

标题栏固定 36px，窗口按钮 28px。侧栏导航行 28px。

## 颜色和状态

面板是一层表面，输入和未激活项更弱一层，悬停、按下、选中再往上走。文字分主、次、更弱三档。

输入框聚焦时加一圈中性描边，不改底色，也不用蓝色去描。打开的菜单用更轻的边。错误优先用危险色；聚焦在错误上时保持错误描边。蓝色留给主按钮、开关打开、滑杆有值这些「值本身就是强调」的地方。

卡片默认没有描边。需要抬起来用阴影，不要用浅线冒充阴影。选中的卡片用柔和的选中底，不用蓝色包边。

深色和浅色只换颜色，不换尺寸，也不换状态怎么分层。

## 字体

正文字体是 Noto Sans SC 的四档字重。应用接入时要注册这套字体，并把它设为界面默认字体。仓库里的示例已经做了这一步。未注册时才会落到系统字体，那不能当作设计稿。

## 圆角

外观设置里只暴露一个「标准圆角」。内部按四级差开微型、控件、卡片、页面。默认 10px，对应 2 / 6 / 10 / 14。改了立刻作用到公共控件。

主区域贴着展开的侧栏时，挨着侧栏的那两个角会收成直角，另一侧保持页面圆角。关掉主区域圆角后四角都是方的。

## 浮层和拖拽

菜单默认和触发它的按钮起始边对齐，靠近窗口边缘时由控件自己收回来，应用不要去算坐标。

可以拖的 Tab 和列表：按下后移动超过 4px 才算拖，落点用一条细的强调色插入线。点击仍然只是选中。拖放不会长出 Dock 那种占位卡。

命令面板宽 680px，搜索行 32px，结果行 40px。打开后输入框必须真正拿到焦点；上下键移动、Enter 执行、Escape 关闭并恢复焦点。结果只能来自当前上下文里真正接了 handler 的 Action。

树按侧栏的深度步进和省略规则。上下在可见节点间移动，左先折叠再回父级，右先展开再进第一个子节点。选择和展开用稳定 ID 回传，不用标签或绘制序号当身份。

分栏的 chrome 高 34px。高亮只表示当前 pane。关闭一条内容和关掉空 pane 是两件不同的事，没有真实 handler 的动作不要画上去。

标题栏 36px 三列：左右等分，标题几何居中，窗口按钮 28px。空白处移动超过 4px 才拖窗口。macOS 给红黄绿让出 78px；Windows / Linux 自绘最小、最大、关闭，关闭用危险色。

侧栏折叠 240ms，分组展开 160ms，都是 ease-out。只有动画在跑时才要帧，反向从当前进度接着走，结束不空转。

## 内部如何工作

颜色和尺寸来自共享的 `ThemeTokens` / `ThemeMetrics`，不是每个控件一份样式表。`AppearanceSettings` 只暴露标准圆角，内部按 4px 级差派生四级。控件从当前 tokens 读 `ControlSize`，不再私藏行高。

主区域圆角由工作区表面统一画，并用角部遮罩卡住内容，不靠页面自己设相同圆角。对应侧有展开的 Region 时保留页面圆角，主区域变成该行第一个或最后一个轨道时，那一侧上下两角归零。

字体由 `ui_font_sources()` 注册 LiliaUI 同源的 Noto Sans SC。未注册才落到系统字体。快照和窗口 Gallery 走同一套 Runtime 文档和 `SceneWgpuPainter`；离屏回读只属于验收工具，正式窗口不会走这条读取。
